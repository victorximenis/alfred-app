Alfred

Assistente de voz pessoal para macOS, de uso próprio do autor.

O Alfred roda inteiramente no computador do usuário. Com autorização explícita, ele pode ler a agenda e os e-mails das contas Google e Microsoft do próprio usuário para responder perguntas por voz. O acesso é somente leitura.

Política de privacidade

  • Dados acessados. Eventos da agenda e mensagens de e-mail das contas que o próprio usuário conectar, apenas para leitura (escopos calendar.readonly e gmail.readonly no Google; Calendars.Read e Mail.Read na Microsoft).
  • Uso. Os dados são usados só para responder a pedidos do próprio usuário, no momento do pedido. Não há uso para publicidade, perfilamento ou treinamento de modelos.
  • Armazenamento. Os tokens de acesso ficam cifrados pelo Keychain do macOS no computador do usuário. O Alfred não mantém servidor próprio e não guarda cópias de e-mails ou eventos.
  • Compartilhamento. Trechos necessários para responder um pedido são enviados ao modelo de linguagem que o usuário configurou na própria conta. Nenhum dado é vendido ou compartilhado com terceiros.
  • Revogação. O usuário pode desconectar a qualquer momento pelo menu do Alfred, o que apaga o token local, e revogar o acesso em myaccount.google.com/permissions ou account.live.com/consent/Manage.

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Termos de uso

O Alfred é um projeto pessoal, sem fins comerciais, usado apenas pelo próprio autor. É fornecido "como está", sem garantias. Ao conectar uma conta, o usuário autoriza somente a leitura descrita acima e pode retirar essa autorização a qualquer momento.
